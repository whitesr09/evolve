# EVOLVE

EVOLVE is a mobile-first real-life RPG for personal growth, productivity, simulations, and skill development.

## v0.1

The first playable build includes:
- Switchable dark futuristic and bright Liquid Glass themes
- Player profile for N S H D
- XP, levels, ranks and streaks
- Seven core player stats
- Daily quests with persistent progress using browser LocalStorage
- Training-zone placeholders for Decision Lab, Social Arena, Career Sim, Business Sim, English Arena and Life RPG

## Current architecture

EVOLVE v0.1 is intentionally zero-cost and phone-friendly: plain HTML, CSS and JavaScript with no build step and no paid backend. It can be hosted directly with GitHub Pages.
